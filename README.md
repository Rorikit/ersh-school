# ЁРШ CRM

React + TypeScript + Vite. Исходные материалы: `code.html`, `screen.png`, `DESIGN.md`. Tailwind собирается локально, CDN Tailwind не используется.

## Запуск

```sh
npm install
npm run dev
```

Приложение: http://localhost:5173. Проверки: `npm run build`, `npm run typecheck`. Браузерные сценарии: `node scenarios.mjs` (после `npx playwright install chromium`).

## Данные

Типы и адаптер localStorage — `src/data.ts`; начальные занятия — `src/seed.json`. Дата эталона фиксирована: 18.10.2024. Сводки дня и недели — самостоятельные демонстрационные данные, а не расчёт по шести карточкам. Платежи, записи учеников, группы и черновики сохраняются локально, без сервера и отправки сообщений.

Сброс: в консоли браузера выполнить `localStorage.removeItem('ersh-demo-v1'); location.reload()`. Действие удаляет только демонстрационные данные этого приложения.

Исходная разметка разложена через React-парсер на React-элементы; обработчики и динамические карточки реализованы в React. Нет iframe или подмены страницы изображением. Шрифты Inter и Material Symbols загружаются Google Fonts и требуют подключения к сети.

Все пункты навигации кроме главной представлены оболочкой: Расписание, Занятия, Ученики, Группы, Преподаватели, Финансы, Статистика, Настройки. Для них не предоставлены макеты.

Ранее обсуждённые бизнес-требования не присутствуют в текущем проекте: сравнить их с макетом без исходного перечня невозможно. Административные наблюдения не добавлены в композицию. В эталоне сохранены противоречивые сводки (24 в topbar, 28 в KPI), учебный корпус и кампус, демонстрационные инциденты вне шести видимых карточек.

## Проверка результата

Выполнены `npm run build`, `npm run typecheck` и браузерные сценарии `npm test` при запущенном dev-сервере. Проверены поиск/пустая выдача, фильтры/дни, создание и ошибка времени, посещаемость, перенос/отмена с причиной, оплата, сохранение после перезагрузки, создание группы и запись ученика, конфликт, замена, локальный черновик, уведомления, навигация, Escape, возврат фокуса и сохранение полей после отказа от закрытия.

Снимки: `artifacts/actual.png` (1469×1600), `artifacts/comparison.png` (рядом с эталоном), `artifacts/screen-1440.png`, `screen-1280.png`, `screen-768.png`, `screen-390.png`. Шрифты перед финальным снимком загружены. На четырёх дополнительных ширинах проверено отсутствие горизонтальной прокрутки, ошибок JavaScript не обнаружено.

Остаются небольшие отличия в начертании и переносах отдельных подписей, контурах части иконок и аватаре (локальный фирменный знак вместо внешней фотографии). Компоновка новых форм не имеет эталона. В исходном HTML и screenshot по-разному переносятся заголовки и данные, поэтому общий масштаб выбран по изображению. Это не заявление о полном попиксельном совпадении.
