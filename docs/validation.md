# Фактическая локальная проверка

Среда: Windows, Node v24.16.0, npm, Chromium Playwright из lockfile. Используются синтетические данные; рабочие БД и чужой браузер не очищались. Отдельные проверки — результат запуска, прочие ограничения ниже — статические выводы и границы доказательств.

## Выполненные команды

| Команда | Результат |
|---|---|
| `npm ci` | Установка по новому lockfile, код 0 |
| `npm run build` | TypeScript клиента/сервера и Vite, код 0 |
| `npm run typecheck` | Отдельный прогон, код 0 |
| `npm test` | 24 предметных, API, CSV и backup-теста прошли |
| `npm run test:e2e` | 11 независимых браузерных тестов прошли, включая screenshot assertion без обновления эталона |
| `npm audit` | 0 известных уязвимостей в установленном дереве на момент проверки |
| `npm run benchmark` | Синтетические 10 000 учеников / 100 000 занятий; результаты в benchmark.json |
| `git diff --check` | Нет ошибок whitespace |

Сборка сообщает предупреждения Rollup о комментариях PURE в Zod; комментарии удаляются сборщиком, сборка завершается успешно. Преднамеренно вызванные 500/503 в API-тестах выводят безопасные correlation ID; это ожидаемые проверки, а не необработанные исключения.

## Предметные и API-проверки

- Даты, часовой пояс и смена суток, високосный день, точные копейки и отказ лишних десятичных знаков.
- Конфликты преподавателя, комнаты и ученика, разрешённые касающиеся границы, недоступность и календарь.
- Запись с даты, запрет дубля, неизменность закрытого состава, вместимость.
- Переходы статусов, отмена, недоступность явки до окончания, закрытый период.
- Недельная серия, перенос дат всей будущей части и сохранение ID, исключение каникул, атомарный отказ серии.
- Выдача → начисление → оплата → явка → дебет → остаток; обратная явка → кредит → возврат; дополнительное исправление после частичного возврата.
- Связанная отработка после уважительного пропуска и запрет её дубля.
- Повтор оплаты/явки с тем же ключом, повтор с другим телом, две версии, откат частично выполненной команды.
- Разные правки полей объединяются после 409; конфликт одного поля отклоняется.
- Перезапуск файловой БД сохраняет реестр и ключи идемпотентности.
- Повреждённый JSON/схема не заменяются пустым Store.
- Представители, ссылки, рабочие часы, календарь и уведомления.
- 401/403, ограничения ролей, чужие школа/филиал/занятие, CSRF, Origin, истечение и logout; malformed JSON, 422, 409, безопасные 500/503 и request ID.
- CSV: preview без записи, кавычки/разделитель, валидация, полный rollback дубля, защита формул в выгрузке.
- Backup API → проверка копии → восстановление в новый файл → сравнение; запрет перезаписи существующего назначения.
- Контракт TestAdapter стабилен и имеет realDelivery:false; UnconfiguredAdapter честно отказывает.

## Независимые браузерные тесты

Каждый тест получает свой HTTP-сервер, SQLite :memory:, cookie-контекст и фиксированные часы. Нет обращения к предварительно открытой вкладке пользователя. Проверены:

1. Полный основной цикл от нового ученика до остатка 3 из 4 и нулевого долга после reload.
2. Ошибка времени; сохранение несохранённых полей; Escape, Tab внутри native dialog и возврат фокуса.
3. Прямые URL восьми разделов, reload, Back/Forward, 404, профиль результата поиска; роль преподавателя и прямой запрещённый API.
4. Потеря сетевого ответа **после реального сохранения**: повтор с тем же ключом не дублирует запись, поля не теряются.
5–8. Ширины 390/768/1280/1440: нет горизонтального overflow документа, мобильное меню и форма читаемы; axe с WCAG A/AA-тегами не выявил нарушений на проверенных экранах.
9. Визуальная регрессия главной 1440×1000, локальные шрифты загружены, фиксированный тестовый день, допуск 1%. Эталон предварительно просмотрен; последующий прогон выполняется без `--update-snapshots`.
10. CSV preview → сохранение; строка `<img ...>` остаётся текстом, элемент img не появляется.
11. Два администратора в отдельных контекстах: конфликт версии сохраняет форму; повтор изменения имени не затирает сохранённый другим сотрудником контакт.

## Что этим не подтверждено

Ни один локальный тест не доказывает внешние TLS/HTTPS, заголовки после reverse proxy, удалённые бэкапы/RPO/RTO, реальные платёжные/кассовые/коммуникационные интеграции. Автоматический axe не заменяет NVDA и ручную WCAG-приёмку. Нет доказательств по Safari/Firefox/реальным телефонам и экранной клавиатуре, browser zoom 200–400%. Бенчмарк — только синтетический сервер в памяти, не SLA и не замер сети/клиента. Клиент пока получает весь агрегат школы, несмотря на наличие пагинационного endpoint. Локальные тесты не выдаются за результат GitHub Actions; внешний статус проверяется отдельно после push.
